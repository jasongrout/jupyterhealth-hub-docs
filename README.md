# JupyterHealth Hub Documentation

User docs for the JupyterHealth JupyterHub at https://jupyter-health.2i2c.cloud.
It is part of the [JupyterHealth docs](https://github.com/jupyterhealth/jupyterhealth-docs), which provide the shared navbar, footer, and glossary used here.

Preview the documentation locally with [nox](https://nox.thea.codes):

```bash
nox -s docs:live
```
