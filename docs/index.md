# JupyterHealth Hub

The JupyterHealth Hub is a cloud-hosted JupyterLab environment for working with health data from the [JupyterHealth Exchange](https://jupyterhealth.org).
It is part of the [JupyterHealth](https://jupyterhealth.org) project and is operated by [2i2c](https://2i2c.org).
