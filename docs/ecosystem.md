# JupyterHealth ecosystem

The hub is one piece of [JupyterHealth](https://jupyterhealth.org), an open platform for bringing wearable and clinical data into Jupyter.
Below are a few other pieces of technology in the JupyterHealth ecosystem and where you can learn more.

% This should be in a JupyterHealth core landing page site probably!
```{listing}
:source: yaml
:columns: title,description
- title: JupyterHealth Exchange
  url: https://jupyterhealth.github.io/software-documentation/
  description: Stores patient-consented health data and handles login for the hub.
- title: JupyterHealth client
  url: https://jupyterhealth-client.readthedocs.io
  description: Python library for pulling data from the exchange into a notebook. Pre-installed on the hub.
- title: CGM tutorial
  url: https://jupyterhealth.github.io/software-documentation/tutorial/tutorial-cgm
  description: End-to-end example of analyzing continuous glucose monitor data with the client.
- title: Demos
  url: https://jupyterhealth.github.io/demos/
  description: Example dashboards you can open directly on the hub.
- title: Single-user image
  url: https://github.com/jupyterhealth/singleuser-image
  description: The software environment your hub server runs.
- title: SMART on FHIR extension
  url: https://github.com/jupyterhealth/jupyter-smart-on-fhir
  description: Lets clinical systems launch the hub with a patient in context.
```
